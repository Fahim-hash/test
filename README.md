# Fahim — Portfolio v2

A redesigned, editorial-style portfolio for **Syed Fahim Muddasir**, focused on visual identity, campaigns, digital experiences, motion and photography.

## Direction

- Bold editorial typography
- Minimal monochrome system with acid-lime accent
- Responsive mobile navigation
- Case-study focused project grid
- Capability cloud + software proficiency
- Career / experience timeline
- Testimonial section
- Direct email + social links
- Lightweight Next.js App Router implementation

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```

## Notes

This is the **new portfolio build**. The original `Fahim-hash/portfolio` repository was not edited.
